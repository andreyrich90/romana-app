# Română.

Приложение для изучения румынского языка в формате коротких уроков — как Duolingo. Объяснения на русском и украинском. iOS и Android из одного кода (Expo / React Native).

## Что уже есть

- Первый запуск: язык объяснений, уровень «на глаз» и короткий тест (3 вопроса на каждые два раздела, из настоящих заданий курса). По итогам приложение открывает всё до подходящего раздела; новичок начинает с раздела «Алфавит и чтение» (5 уроков: знакомые буквы, ă â î, ș ț, ce/chi/ge/ghi, чтение). Тест можно пройти снова из профиля.
- Нажмите на любое румынское слово в карточке, таблице грамматики или ответе — откроется окно «Смысл фразы»: перевод всей фразы, как она читается, и каждое слово с переводом, частью речи и начальной формой (словарь — `src/content/glossary.ts`, 520 форм). Пока задание «выберите перевод» не решено, окно показывает только слова, без готового ответа. У каждого слова есть кнопка «👛 В кошелёк»: сохранённые слова собираются во вкладке «Кошелёк» в словаре и синхронизируются с аккаунтом. Кнопка «Тренировать слова» (в кошельке и на главном экране) собирает из них короткий урок: перевод, выбор румынского слова, аудирование и пары.
- Карта курса A1: 6 разделов × 5 уроков, уроки открываются по очереди.
- Уровень A1 готов целиком: 6 разделов, 30 уроков, 370 заданий семи типов:
  новое слово, грамматическая карточка, выбор перевода (в обе стороны), аудирование, сборка фразы из плиток, пары, письменный ответ.
- Уровень A2 готов целиком (`docs/curriculum-a2.md`): 6 разделов, 30 уроков — прошедшее и будущее время, să + глагол, у врача, покупки (родительный и дательный падежи), путешествия (местоимения îl, o).
- 5 жизней, полоса прогресса, повтор ошибок в конце урока, итоговый экран (опыт, точность, время).
- Проверка письменных ответов прощает пропущенную диакритику и одну опечатку, но показывает правильное написание.
- Кнопки ă â î ș ț под полем ввода.
- В письменных заданиях — кнопка «Выбрать из слов»: ответ собирается из плиток (слова ответа + лишние слова из того же урока). Выбор запоминается.
- Озвучка румынским голосом устройства (`expo-speech`).
- Опыт, серия дней подряд и пройденные уроки сохраняются на устройстве, а после входа — ещё и в аккаунте (Supabase), чтобы продолжить на другом телефоне или в браузере. Без входа всё работает как раньше.
- Цель дня (10/20/30/50 опыта) и серия дней подряд: день засчитывается, когда цель выполнена. Заморозки серии: одна за каждые 7 дней, до двух, прощают пропущенный день.
- Тренировка слабых мест: интервальное повторение (коробки Лейтнера) — каждое задание, где ошиблись, возвращается сегодня, остальные — через 1, 3, 7, 14 и 30 дней.
- Профиль: уровень по опыту, график недели, выбор цели, 13 достижений.
- Словарь: все слова пройденных уроков с поиском и озвучкой.
- Светлая и тёмная тема.

## Запуск

Нужны Node.js 20+ и приложение **Expo Go** на телефоне (App Store / Google Play).

```bash
npm install
npx expo start
```

Отсканируйте QR-код из терминала камерой (iPhone) или в Expo Go (Android).

Веб-версия для быстрой проверки: `npx expo start --web`.

## Аккаунты (Supabase)

1. Создайте проект на https://supabase.com (бесплатный тариф).
2. **SQL Editor → New query**: вставьте `supabase/schema.sql` и нажмите **Run**. Появится таблица `progress` с защитой строк (каждый видит только свои данные) и функция удаления аккаунта.
3. **Authentication → URL Configuration**: в **Site URL** укажите адрес сайта (`https://romana-app-seven.vercel.app`) — туда ведут ссылки из писем.
4. **Project Settings → API**: скопируйте **Project URL** и **anon public** ключ в `.env.local` (образец — `.env.example`) и в переменные окружения проекта на Vercel.

Без этих ключей приложение работает в гостевом режиме и не показывает кнопку входа.

### Вход через Google

Кнопка «Войти через Google» появляется сама, как только Google включён в Supabase: приложение читает публичные настройки проекта (`/auth/v1/settings`). Пересобирать ничего не нужно.

1. **Google Cloud Console** (https://console.cloud.google.com) → создайте проект → **APIs & Services → OAuth consent screen**: тип *External*, название «Română», почта поддержки. Опубликуйте экран (*Publish app*), иначе войти смогут только тестовые пользователи.
2. **APIs & Services → Credentials → Create credentials → OAuth client ID**, тип **Web application**. В **Authorized redirect URIs** добавьте адрес из Supabase: `https://<ваш-проект>.supabase.co/auth/v1/callback` (его показывает Supabase на шаге 3). Скопируйте **Client ID** и **Client secret**.
3. **Supabase → Authentication → Sign In / Providers → Google**: включите, вставьте Client ID и Client secret, сохраните.
4. **Supabase → Authentication → URL Configuration → Redirect URLs**: добавьте `romana://auth-callback` (приложение из магазина) и `exp://**` (проверка в Expo Go). Для сайта ничего добавлять не нужно — он возвращается на Site URL.

## Структура

```
src/
  app/                 экраны (Expo Router)
    index.tsx          карта курса
    lesson/[id].tsx    прохождение урока и итоги
  content/             курс: типы, карта разделов, уроки
  engine/              логика урока без интерфейса: проверка ответов, очередь заданий
  components/          кнопки, карточки, все типы упражнений
  i18n/ui.ts           тексты интерфейса RU / UA
  state/progress.tsx   прогресс ученика (AsyncStorage)
docs/curriculum-a1.md  программа уровня A1
docs/curriculum-a2.md  программа уровня A2
```
