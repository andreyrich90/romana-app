# Română.

Приложение для изучения румынского языка в формате коротких уроков — как Duolingo. Объяснения на русском и украинском. iOS и Android из одного кода (Expo / React Native).

## Что уже есть

- Карта курса A1: 6 разделов × 5 уроков, уроки открываются по очереди.
- Готовы разделы 1 «Первые шаги» и 2 «Семья» — 10 уроков, 122 задания семи типов:
  новое слово, грамматическая карточка, выбор перевода (в обе стороны), аудирование, сборка фразы из плиток, пары, письменный ответ.
- 5 жизней, полоса прогресса, повтор ошибок в конце урока, итоговый экран (опыт, точность, время).
- Проверка письменных ответов прощает пропущенную диакритику и одну опечатку, но показывает правильное написание.
- Кнопки ă â î ș ț под полем ввода.
- Озвучка румынским голосом устройства (`expo-speech`).
- Опыт, серия дней подряд и пройденные уроки сохраняются на устройстве.
- Светлая и тёмная тема.

## Запуск

Нужны Node.js 20+ и приложение **Expo Go** на телефоне (App Store / Google Play).

```bash
npm install
npx expo start
```

Отсканируйте QR-код из терминала камерой (iPhone) или в Expo Go (Android).

Веб-версия для быстрой проверки: `npx expo start --web`.

## Проверки

```bash
npm run typecheck
npm run lint
```

## Структура

```
src/
  app/                 экраны (Expo Router)
    index.tsx          карта курса
    lesson/[id].tsx    прохождение урока и итоги
  content/             курс: типы, карта разделов, уроки
  engine/              логика урока без интерфейса: проверка ответов, очередь заданий
  components/          кнопки, карточки, все типы упражнений
  i18n/ui.ts           тексты интерфейса RU / UA
  state/progress.tsx   прогресс ученика (AsyncStorage)
docs/curriculum-a1.md  программа уровня A1
```
