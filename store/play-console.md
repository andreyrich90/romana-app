**Новостное приложение:** нет. **Госорган:** нет. **Финансовые функции:** нет. **Здоровье:** нет.

## Безопасность данных (Data safety)

- **Собирает ли приложение данные?** Да.
- **Все данные шифруются при передаче?** Да (HTTPS).
- **Можно ли запросить удаление данных?** Да — в приложении (главный экран → Аккаунт → Удалить аккаунт) и по ссылке https://romana-app-seven.vercel.app/delete-account

| Тип данных | Собирается | Передаётся третьим лицам | Обязательно? | Зачем |
|------------|-----------|--------------------------|--------------|-------|
| Личная информация → Адрес электронной почты | Да | Нет | Нет (только при входе) | Управление аккаунтом |
| Личная информация → Имя | Да | Нет | Нет (только при входе через Google) | Управление аккаунтом |
| Личная информация → Другая информация (ссылка на фото профиля Google) | Да | Нет | Нет (только при входе через Google) | Управление аккаунтом |
| Действия в приложении → Прочие действия (прогресс уроков, опыт, серия, цель дня, сохранённые слова) | Да | Нет | Нет (только при входе) | Функции приложения (синхронизация) |

Без входа в аккаунт всё хранится только на телефоне и никуда не отправляется. Аналитики, рекламы, геолокации, контактов и сбора сведений об устройстве нет.
Supabase (хранит аккаунты и прогресс) — обработчик данных по поручению разработчика, это не «передача третьим лицам» в понимании Google.

## Тестирование и выпуск

1. Тестирование → Закрытое тестирование → создать трек, загрузить `.aab` из EAS.
2. Добавить список тестировщиков (не меньше 12 адресов Gmail) и отправить им ссылку для участия.
3. Тестировщики устанавливают приложение и не удаляют его 14 дней.
4. Затем «Рабочая версия» → запросить доступ → отправить на проверку.
